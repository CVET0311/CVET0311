## Why this profile is quiet

Most of what I build is in private repositories. The security correlation platform I am developing hasn’t been released, and the lab documentation describes a live estate, so neither is public. What is here is smaller than what I actually work on.

`omada` is public because it is a standalone install script for the TP-Link Omada controller on Ubuntu Server, and it is useful outside my own environment.

## The lab

Twelve segmented VLANs and around 130 tracked devices and virtual machines, with a deny-by-default firewall policy on every host and an identity provider in front of the applications that support one. Detection, vulnerability scanning and scheduled backups run against it continuously, and it is documented well enough to rebuild from nothing.

Backups get verified by restoring them. Changes get a way back before they are made. Claims come with the command that produced them.
